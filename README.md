# Камеры • Калуга

Экспериментальное приложение для BMW MGU / iDrive 7: локальная база камер Калуги и Калужской области, меню диагностики и отдельные предупреждения в центре приборной панели и на HUD через общий `cluster-render`. **На настоящем автомобиле этот релиз ещё не проверен. Оба выхода первоначально выключены.**

Комплектный снимок OSM содержит **150 точек** области: 36 в городе Калуге, 52 с числовым ограничением скорости. Для условных предупреждений подготовлены 19 зон с направлением камеры и связанной геометрией дороги. Эти числа характеризуют снимок, а не полноту покрытия и не количество фактически работающих комплексов.

## Установка через MGU Store

В уже работающем Store: **Настройки → Добавить источник → `istt1899/bmw-kaluga-cameras` → Releases**, затем приложение **Камеры • Калуга → Установить**. Публичному репозиторию не нужны GitHub-токен и вход в GitHub. Для загрузки пакетов нужен интернет Store; после установки приложение использует локальный снимок.

Пакеты: приложение `marku_kaluga_cameras` и его сервис `marku-kaluga-cameras`, версия 0.1.1. Минимальные зависимости указаны в каталоге: `mgu-deploy` 0.7.11 и `cluster-render` 0.4.0. Устанавливать на неподвижной машине со стабильным питанием. Перезапустить MGU, если Store покажет такое требование.

Без интернета можно подготовить USB на компьютере: `node tools/build.js`. Содержимое созданной папки `../output/kaluga-cameras-usb/` переносится в корень носителя; в Store используется раздел **USB**. Перед установкой все отсутствующие зависимости должны уже находиться на машине или на носителе. Эта сборка не переустанавливает Store, Waze или доступ SSH.

Откройте **Приложения → Камеры • Калуга** и проверьте GPS, состояние базы и renderer. Выходы на приборку и HUD включаются независимо. Предупреждение размещается в центральной области между штатными шкалами; произвольная перерисовка бумерангов не заявлена. Сервис отправляет отдельный слой предупреждения поверх карты Waze через общий renderer; совместная работа на автомобиле ещё не проверена.

## GPS и ограничения

Сервис поддерживает GPSD / NMEA через предусмотренные локальные входы. Наличие работающего источника координат на конкретной MGU требуется проверить отдельно. Без свежей достоверной позиции и однозначного соответствия дороге/направлению уверенные предупреждения не выдаются. Геометрия 19 зон — ограниченный эксперимент, а не универсальная навигация по всей области.

Меню показывает состояние сервиса и позволяет выбирать выходы. Расстояние, тип камеры и лимит выводятся только по доступным данным. Аудиооповещения, встроенный интернет-обновлятор автомобильной базы, наложение на центральный CarPlay-экран и восстановление подписки ConnectedDrive не реализованы. Кнопки не обещают недоступное обновление. Соблюдайте знаки и ограничения независимо от данных приложения.

## Удаление

В Store удалите сначала приложение **Камеры • Калуга** (`marku_kaluga_cameras`), затем его сервис (`marku-kaluga-cameras`). Общий renderer может использоваться другими приложениями; удалять его для удаления камер не требуется.

## Сборка и публикация

Для сборки из комплектного снимка достаточно Node.js 18+ на компьютере:

```powershell
node tools/build.js
node tools/prepare-github-release.js
```

Первый скрипт создаёт два пакета и локальный USB-каталог. Второй проверяет их контрольные суммы и состав, готовит отдельный чистый экспорт исходников, публичный `catalog.json` и команды для просмотра перед публикацией. Он не входит в GitHub, не отправляет файлы и не исполняет команды `gh`. Повторный запуск требует новой пустой папки через `--output`.

Для обычной сборки не нужны PBF и npm-зависимости. Дополнительный генератор `tools/build-road-zones.mjs` работает на компьютере с тем же публичным региональным PBF, из которого получен комплектный снимок, и `osm-pbf-parser-node` 1.1.4. Он проверяет соответствие контрольной сумме; другой PBF требует согласованного обновления исходного снимка и геометрии. Этот генератор не является обновлятором на MGU.

GitHub-источник Store на канале **Releases** читает asset `catalog.json` из релиза с тегом **`catalog`**. Два версионных архива публикуются первыми, каталог — последним. Один статический `catalog.json` в ветке не заменяет этот release: канал ветки ожидает `mgu-repo.json`. Отдельный HTTPS-каталог — другой поддерживаемый тип источника. [Форматы MGU Store](https://github.com/robertnisipeanu/mgu-store/blob/main/docs/PUBLISHING.md).

Закрытый BMW OAP SDK не включён в исходники и архивы. HMI-приложение собирается на головном устройстве с подходящим установленным SDK donor. Успешная сборка на компьютере не подтверждает правильность установки, GPS и расположения слоёв на автомобиле.

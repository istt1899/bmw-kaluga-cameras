Исполняемые сценарии подтверждают: шесть переходов в корне; общий lifecycle registry; canonical Back; прямой selector диагностики; отсутствие записей при открытии; отдельные HUD/map; видимые baseline значения до применения; Done только после точного terminal результата, остановки и постоянного сохранения; полный текст отказов. Проверены обе очередности visibility событий, overlay/reopen, active hold→Back и поздние getter/ACK.

Для wall2179→2026 проверены прежний debounce400мс и отдельный release-tail450мс, новый reset ID, снятие старого hold, ограниченный pending move. Реальный локальный decoder/provider/service показывает полный RMC UTC, signed receipt delta и cutoff; отрицательный возраст остаётся неизвестным. Старый cutoff не принимается за пригодные новые координаты; явный reset и новая серия восстанавливают локальный тест. Правила3с/+500мс,≤1км/ч test и15м road не ослаблены.

Legacy fixture читает реальный файл0.7 с разными HUD/map, отключёнными типами и нестандартными порогами; ни чтение, ни статус не пишут его. Preview заменяется только явной командой, выбранный reset не трогает другой профиль. Done и новый процесс сохраняют значения; EROFS показывает temporary и после restart возвращает последний durable файл.
